# Preliminary page-opportunity map (search-intent ownership)

**Not a final Academy TOC.** Each row is a *candidate URL or section* that should own one principal intent. Secondary phrases roll up to the same owner (see `cannibal_group` in CSV).

**Scale estimate (evidence-based, pre-volume):** **~45–75 distinct, worthwhile URLs** in the core commercial + website-research lane, plus **~35–55** owner-focused growth articles where SERP confirms business-owner intent — **~80–130 total** before optional competitor-brand comparison spokes. This is **far below 1,000** unless you deliberately publish geo/agency-style pages (not recommended under Phase 1 audience rules).
