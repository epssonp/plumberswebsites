# Phase 1H — Master TOC README

## Purpose

Produce the **article-level master Table of Contents** (~300 standalone opportunities) under the approved Phase 1F category and Phase 1G subcategory architecture.

## Method

1. Load **24 subcategories** from `../phase1g-subcategory-review/subcategory-master.csv` (counts are authoritative).
2. Assign **one distinct article per slot** via curated topics in `article_topics.py` (no synonym padding).
3. Map **Phase 1E AC-01–AC-11** into standalone URLs or merged sections (`ac01-ac11-reconciliation.csv`).
4. Apply **evidence labels** from Phase 1C–1D only where supported; otherwise `intent_hypothesis` or `unverified_candidate`.
5. Seed **internal links** for Wave 1 pillars in `master-internal-linking-map.csv` (expand during drafting).

## Evidence

- Ahrefs Free **bands** (2026-10-18) are not exact monthly volumes.
- **No numeric_volume** in CSV unless a future Semrush export adds verified figures.
- Missing Ahrefs rows = `no_exact_match_returned`, not zero demand.

| File | Description |

## Regenerate

```bash
python research/phase1h-master-toc/generate_phase1h_toc.py
python research/phase1h-master-toc/validate_phase1h_toc.py
```

## Updating after Semrush

Add numeric volumes and revised evidence_status in a **copy** or new phase folder; do not overwrite Phase 1C–1D sources. Prefer updating `article_topics.py` primary_keyword/evidence fields and regenerating.
